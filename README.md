# 撬藤壶解压 · Barnacle Print Kit

这个项目主要是为了让大家 **把藤壶打印出来，再一颗颗或一组组撬下来，体验撬藤壶的解压乐趣**。

## 👉 [直接下载成品：解压藤壶打印文件](解压藤壶打印文件/)

无需运行代码。中文文件夹中直接提供可打印的整盘、试打和分件文件：

- **独立版**：50 颗各自独立，逐颗取下。
- **新增群落版**：30 颗组成 3、4、5、6、6、6 颗的六组相连群落，另有 20 颗独立，可整组取下。
- 两版均在 **200 × 200 毫米**范围内，**最高 15 毫米**，没有共同打印底板。

请先少量试打，确认适合自己的平台与材料。文件已检查，尚未实物试打；具体撬下手感仍需实际确认。

## 独立版尺寸与使用

| 项目 | 最终版本 |
| --- | --- |
| 数量 | 50 颗独立藤壶 |
| 摆放区域 | 200 × 200 mm |
| 实际外包尺寸 | 约 185.661 × 187.552 × 15.000 mm |
| 最高点 | 15.000 mm |
| 整体缩小比例 | 原版各颗长宽高同时乘 0.5033557176 |
| 颗粒间最小平面间距 | 约 7.736 mm |
| 实物试打 | 未完成 |

导入切片软件时选择毫米、100% 大小。先使用三颗试打文件确认薄边和细节，再打印整盘。不要把展示用深色底板当成打印内容。剥离手感受材料、平台和打印设置影响，这份文件不保证特定手感。
